# Логотип Own Backup

- `logo-1.png` — исходник, оранжевый вариант: слева знак, справа знак с
  надписью «Own Backup». Прозрачный фон, 1774×887.
- `logo-2.png` — то же в фиолетовом варианте.

Знак из `logo-1.png` — тот, что в программе: большой знак в боковой полосе окна
(`crates/gui/frontend/src/assets/logo.png`, он же в шапке README) и значки
исполняемого файла, окна и области уведомлений (`crates/gui/icons/`).
Изображения из этой папки в программу не встраиваются.

`backup-forder.png` — исходник картинок страницы задания: слева источник, справа
назначение, тёмный фон со свечением. Вырезанные из него значки с прозрачным фоном —
`crates/gui/frontend/src/assets/backup-dest.png` (папка).

`disks.png` — исходник диска, прозрачный фон: слева без замка, справа с замком.
Из него `assets/backup-source.png` и `backup-source-locked.png`; диск с замком
показывается, когда источник задания зашифрован.

`own_backup_512_fit.webp` — движущийся логотип, увеличенный до левого и правого края
квадрата (границы общие для всех кадров). Из него собрана лента кадров значка на время
задания, `crates/gui/icons/busy-frames.png`: 16 кадров по 48 пикселей, один под другим.
