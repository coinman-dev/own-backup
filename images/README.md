# Логотип Own Backup

- `logo-1.png` — исходник, оранжевый вариант: слева знак, справа знак с
  надписью «Own Backup». Прозрачный фон, 1774×887.
- `logo-2.png` — то же в фиолетовом варианте.

Знак из `logo-1.png` — тот, что в программе: большой знак в боковой полосе окна
(`crates/gui/frontend/src/assets/logo.png`, он же в шапке README) и значки
исполняемого файла, окна и области уведомлений (`crates/gui/icons/`).
Изображения из этой папки в программу не встраиваются.
