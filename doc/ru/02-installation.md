# Установка

Файлы скачиваются со
[страницы выпусков](https://github.com/coinman-dev/own-backup/releases). В
файле `SHA256SUMS.txt` там лежат суммы SHA-256 каждого файла.

| Файл | Для чего |
|---|---|
| `own-backup-install_<версия>.exe` | Windows 10/11, x64 |
| `own-backup_<версия>_amd64.deb` | Ubuntu 24.04+, Debian 13+, amd64 |
| `OwnBackup-Linux-<версия>_amd64.iso` | Загрузочный носитель Linux (см. [Загрузочный носитель](10-bootable-media.md)) |

## Windows

### Требования

- Windows 10 или 11, 64-разрядная.
- Права администратора для установки (сама программа потом работает без них).
- **Microsoft Edge WebView2 Runtime** для окна. В Windows 11 он есть; если
  его нет в Windows 10, установщик скажет об этом и предложит страницу
  загрузки.

### Установка

1. Запустите `own-backup-install_0.1.9-beta.exe` и подтвердите запрос администратора.
2. Выберите язык мастера (русский или английский) и пройдите его.

Установщик кладёт программу в `C:\Program Files\OwnBackup` для всех
пользователей компьютера, регистрирует и запускает службу **Own Backup**,
добавляет программу в меню «Пуск» и запускает значок в области уведомлений для
текущего пользователя.

**Обновление** — то же самое: запустите новый установщик поверх старой
версии. Настройки, задания и история сохраняются. Обновлять можно и во время
копии: установщик сначала останавливает службу, а прерванная копия
повторяется по расписанию.

### Тихая установка

```
own-backup-install_0.1.9-beta.exe /S
own-backup-install_0.1.9-beta.exe /S /D=D:\Programs\OwnBackup
```

`/S` ставит без вопросов. `/D=<папка>`, обязательно последним аргументом,
выбирает папку первой установки.

### Удаление

Через **Параметры → Приложения** (или «Программы и компоненты»).
Деинсталлятор спрашивает, оставить ли настройки, задания и историю; тихое
удаление оставляет их всегда. **Резервные копии при удалении не трогаются
никогда.**

## Linux

### Требования

- Ubuntu 24.04 и новее или Debian 13 и новее; amd64.
- systemd (служба — юнит systemd) и polkit.
- Библиотеки для окна (WebKitGTK и другие) пакет ставит сам. Рекомендуемые
  пакеты — `lvm2`, `cryptsetup-bin`, `ntfs-3g`, `debootstrap` и другие — `apt`
  ставит по умолчанию; они нужны для снимков LVM, LUKS, удаления имён NTFS и
  сборки загрузочного носителя.

### Установка

```bash
sudo apt install ./own-backup_0.1.9.beta_amd64.deb
```

Пакет кладёт окно и командную строку в `/usr/bin`, службу — в
`/usr/libexec/own-backup`, включает и запускает юнит systemd `own-backup` и
добавляет окно в меню приложений.

**Доступ.** Пользоваться службой могут только члены группы `own-backup` и
только из локального сеанса (не через SSH). Первая установка из терминала
добавляет в группу того, кто запустил `sudo apt install`. **Выйдите из
системы и войдите снова**, чтобы членство вступило в силу. Дать доступ другому
пользователю:

```bash
sudo own-backup-service --grant-access ПОЛЬЗОВАТЕЛЬ
```

Окно предлагает то же самое (через запрос пароля), если видит, что вас нет в
группе.

Некоторые действия дополнительно спрашивают у polkit пароль администратора:
восстановление на диск, удаление копий, управление ключами, сборка
загрузочного носителя, изменение записей загрузки.

### Обновление

Установите новый пакет так же. Идущая копия аккуратно останавливается и
повторяется по расписанию.

### Удаление

```bash
sudo apt remove own-backup     # программа; настройки, задания и ключи остаются
sudo apt purge own-backup      # ещё и /var/lib/own-backup (настройки, задания, ключи)
```

Пока служба работает, purge данные не удаляет. Резервные копии не удаляются
никогда.

## После установки

Откройте **Own Backup** из меню «Пуск» (Windows) или меню приложений (Linux).
Окно открывается на странице **Резервное копирование**; пока заданий нет, оно
предлагает создать первое — см. [Быстрый старт](04-quick-start.md).

У окна есть **значок в области уведомлений**. Он запускается вместе с сеансом;
закрытие окна оставляет значок, а служба выполняет расписание независимо от
того, открыто окно или нет.
