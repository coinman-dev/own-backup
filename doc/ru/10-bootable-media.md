# Загрузочный носитель

Загрузочный носитель — небольшая операционная система с Own Backup, которая
запускается с флешки, CD/DVD или ISO, подключённого к виртуальной машине. Он
нужен, чтобы:

- восстановить **системный диск** — работающая система не может перезаписать
  сама себя;
- сделать копию компьютера, который **не запускается**, или диска, пока система
  на нём выключена (снимок тогда не нужен);
- восстановить копию на **новый пустой диск** или на другой компьютер.

Соберите его **сейчас**, пока компьютер исправен, и проверьте, что компьютер с
него запускается.

Носителей два вида. На обоих работает то же окно: копирование,
восстановление, подключение, проверка, загрузка компьютера.

## На основе среды восстановления Windows (Windows)

Собирается в Windows из того, что уже есть на машине: среды восстановления
Windows (`Winre.wim`), программы с окном, среды WebView2 и, по желанию,
драйверов этого компьютера. NTFS и ReFS читает сам.

**Инструменты → Загрузочный носитель → На основе Microsoft Windows Recovery
Environment (x64) → Нажмите, чтобы настроить и собрать →** открывает диалог сборки:

- **Куда сохранить ISO.**
- **Сжимать WebView2 в образ** — ISO меньше примерно на 280 МБ, но при загрузке
  среда занимает около 260 МБ памяти (WinPE держит весь образ в памяти). Без
  сжатия ISO больше, а память при загрузке свободна.
- **Добавить драйверы этого компьютера** — сборка опрашивает диски и сетевые
  адаптеры и предлагает драйверы, которых нет в Windows. Без них носитель
  может не увидеть диски NVMe и RAID.
- **Средства на всякий случай** — программы этого компьютера (например,
  файловый менеджер), которые кладутся на носитель вместе с их настройками.
- **Разрешение экрана на носителе** — подсказка о режиме экрана прошивки.

**Начать** собирает ISO. Отчёт показывает файл, размер, сборку основы и
добавленные драйверы. Запишите ISO на флешку программой Rufus или подобной или
подключите его к виртуальной машине.

Если образ среды восстановления не найден, включите её командой
`reagentc /enable` или выберите `Winre.wim` вручную (**Указать Winre.wim…**),
например взятый из установочного образа Windows. Карточка предупреждает, если
образ собран для другой сборки Windows, чем работающая.

### Работа с носителя

Носитель сразу запускает программу. Внизу экрана — полоса с меню **Пуск**
(программа, командная строка, добавленные средства, **Перезагрузка**,
**Выключение**), кнопками открытых окон, раскладкой клавиатуры и часами.
Закрытие окна программы не завершает сеанс — откройте её снова из **Пуска**.

## На основе Linux (Debian 13)

Live-система Debian 13 с программой на небольшом рабочем столе (labwc) со
своей панелью задач: меню **Пуск** (**Резервное копирование**, **Терминал**,
**Перезагрузка**, **Выключение**), кнопки открытых окон и часы. Загружается
через **UEFI — Secure Boot выключать не нужно** (подписанный загрузчик Debian)
— и через старый **BIOS**. Сама читает ext4, XFS, btrfs, LVM и LUKS и
восстанавливает также копии Windows (NTFS, BitLocker, конфигурация загрузки).

### Как получить

- **Со страницы выпуска:** скачайте `OwnBackup-Linux-<версия>_amd64.iso` и
  сверьте его с `SHA256SUMS.txt`.
- **В Linux, из окна:** **Инструменты → Загрузочный носитель → На основе Linux
  (Debian) x64 → Нажмите, чтобы собрать носитель →**. Диалог спрашивает **Как
  получить носитель?**
  - **Скачать готовый ISO с GitHub** — носитель установленной версии,
    проверенный по суммам выпуска; несколько минут, без пароля
    администратора.
  - **Собрать на этом компьютере** — около 15 минут; скачивается около 1 ГБ
    пакетов Debian и на время занимается около 10 ГиБ; нужен пароль
    администратора.

  С галочкой **Записать на флешку** ISO сразу записывается на выбранную
  флешку.
- **В Windows, из окна:** **Инструменты → Загрузочный носитель → На основе
  Linux (Debian) x64 → Нажмите, чтобы скачать →**. Собирается носитель только
  в Linux, поэтому Windows скачивает с GitHub готовый ISO версии установленной
  программы и сверяет его с контрольной суммой выпуска; записи на флешку там
  пока нет.

### Запись на флешку

В Linux записывает окно: **Записать готовый ISO на флешку…** — выберите ISO и
флешку (предлагаются флешки, карты памяти и съёмные диски, внутренние диски —
никогда). **Всё на флешке стирается.** Образ перечитывается для проверки, и на
флешке создаётся раздел **OBK-LOGS**, куда носитель пишет журналы. В Windows
используйте Rufus, balenaEtcher или подобную программу (журналы тогда остаются
только в памяти).

### Работа с носителя

Выберите флешку в меню загрузки компьютера (обычно F8, F11 или F12 при
включении). Откроется рабочий стол с программой. На других консолях
(Ctrl+Alt+F2…) есть вход в систему для ручного ремонта. Журналы сеанса
пишутся на раздел OBK-LOGS флешки и переживают перезагрузку.

## Заметки

- На носителе служба работает как процесс; на диски компьютера ничего не
  ставится.
- Носитель не хранит задания: добавьте копию через **Восстановление →
  Добавить копию** (файл или папку) и восстановите её. Зашифрованные копии
  спросят пароль или ключ восстановления.
- Новые образы OBK открывает только носитель этой версии или новее:
  пересоберите носитель после обновления программы.
