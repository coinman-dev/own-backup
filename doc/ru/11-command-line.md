# Командная строка

`own-backup-cli` делает из терминала то же, что окно. В Windows он лежит в
`C:\Program Files\OwnBackup` (команды, которые работают с дисками, сами просят
права администратора); в Linux это `/usr/bin/own-backup-cli`.

```
own-backup-cli --help
own-backup-cli <команда> --help
```

## Задания (через работающую службу)

| Команда | Что делает |
|---|---|
| `jobs list` | Задания с их идентификаторами. |
| `jobs run <id>` | Ставит задание в очередь, как **Создать копию**. |
| `jobs cancel` | Отменяет идущую копию. |
| `jobs queue` | Выполняемое задание и очередь. |
| `jobs activity [--limit N]` | Недавняя история запусков (по умолчанию 10 записей). |
| `jobs status` | Версия службы и время работы. |
| `jobs watch` | Поток событий в реальном времени (Ctrl+C — остановить). |
| `jobs versions <id>` | Копии задания на диске: по источникам и цепочкам, с размером и с тем, от какой копии каждая зависит. |
| `jobs show <id>` | Печатает задание как JSON. |
| `jobs template` | JSON нового задания со значениями по умолчанию, как в окне. |
| `jobs save <файл\|->` | Создаёт или заменяет задание из JSON. |
| `jobs new …` / `jobs set <id> …` | Создаёт задание или меняет его политику флагами, без JSON. |
| `jobs delete <id> [--delete-files]` | Удаляет задание, а с `--delete-files` — и его копии. |

## Диски и образы

| Команда | Что делает |
|---|---|
| `list-disks` | Диски и разделы, как их видит программа. |
| `list-backups` | Задания и наборы копий. |
| `verify <образ>` | Проверяет образ (с цепочкой) по контрольным суммам. |
| `mount <образ>` / `unmount <образ>` | Подключает образ как диск / отключает его. |
| `backup …` | Копия тома. |
| `backup-disk …` | Копия целого диска в один загрузочный образ, как у задания. |
| `restore …` | Восстановление тома. |
| `restore-disk …` | Восстановление целого диска — разрушающая операция. |
| `boot` | Записи загрузки UEFI: что прошивка предлагает и куда это ведёт. |
| `driver` | Работает ли подключение: iSCSI-инициатор (Windows), NBD и NTFS (Linux). |

## Загрузочный носитель

| Команда | Что делает |
|---|---|
| `media build …` | Собирает носитель WinPE (Windows), как окно. |
| `media build-linux …` | Собирает Linux-носитель из установленной программы в папку (Linux). |
| `media sticks` | Флешки, на которые можно записать носитель (Linux). |
| `media write-stick …` | Стирает флешку и записывает на неё носитель (Linux). |
| `media cancel` | Останавливает идущую сборку носителя или запись флешки. |

## Служба

В Windows сам `own-backup-service.exe` принимает `/install`, `/uninstall`,
`/start`, `/stop` и `/status` (ими пользуется установщик); `own-backup-cli
service status` показывает то же. В Linux служба — юнит systemd:
`systemctl status own-backup`, `journalctl -u own-backup`.

## Примеры

```powershell
own-backup-cli jobs list
own-backup-cli jobs run 3f2a…
own-backup-cli verify "F:\Backup\Disk_C_Win11\Disk_C_Win11_disk4_inc_20261024-185102.obk"
own-backup-service.exe /status
```

Командная строка переведена не полностью: её сообщения в основном на
английском, часть — на русском.
