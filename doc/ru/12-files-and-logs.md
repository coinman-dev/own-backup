# Файлы, папки и журналы

## Windows

| Что | Где |
|---|---|
| Программа | `C:\Program Files\OwnBackup` |
| Настройки, задания, история запусков, сохранённые пароли томов | `C:\ProgramData\OwnBackup` (`config.toml`, `jobs.json`, `activity.json`, `metadata.db`) — доступно только SYSTEM и администраторам |
| Журнал службы, файл на день, хранится тридцать дней | `C:\Program Files\OwnBackup\Logs\own-backup-service-<дата>.log` |
| Журналы окна и значка | `C:\ProgramData\OwnBackup\Logs\` |
| Копии записей загрузки перед каждым изменением | `C:\ProgramData\OwnBackup\boot` |
| Что помнит окно (тема, выбор языка) | `%LOCALAPPDATA%\com.ownbackup.gui` |

## Linux

| Что | Где |
|---|---|
| Окно и командная строка | `/usr/bin/own-backup-gui`, `/usr/bin/own-backup-cli` |
| Служба | `/usr/libexec/own-backup/own-backup-service`, юнит `own-backup.service` |
| Настройки, задания, история, ключи | `/var/lib/own-backup` |
| Журнал службы | journald (`journalctl -u own-backup`) и `/var/log/own-backup` |
| Копии записей загрузки | `/var/lib/own-backup/boot` |

## Резервные копии

Копии пишутся только туда, куда указано в задании; своих копий программа не
держит. Версия — это один файл с именем

```
<задание>_<источник>_<цепочка>-<full|inc|diff>_<ГГГГММДД-ЧЧММСС>.<расширение>
```

где `<источник>` — `disk<N>` для целого диска или имя тома (например, его
буква), `<цепочка>` — номер цепочки, к которой относится версия (новая полная
версия начинает следующий; см. [Версии и
цепочки](03-concepts.md#версии-и-цепочки)), а расширение — `.vhdx` у полной версии VHDX и `.avhdx` у её
инкрементных и дифференциальных версий (так принято в Windows), `.qcow2` у
qcow2 и `.obk` у всех версий зашифрованного задания. Например
`Disk_C_Win11_disk4_3-inc_20261030-185102.obk` — инкремент цепочки 3. Время —
UTC. У копий, сделанных до 0.1.8-beta, номера цепочки в имени нет, и они
никогда не переименовываются: версия находит ту, что под ней, по этому имени. Каждый
образ несёт свои метаданные (что скопировано, контрольные суммы всех блоков,
разметку диска), поэтому папку с копиями можно перенести или скопировать в
другое место, и она по-прежнему откроется, проверится и восстановится.

Пока копия пишется, у файла временное скрытое имя
(`.own-backup-obk-….tmp.obk` и подобные), и под настоящим именем он появляется
только готовым. Файл, оставшийся от прерванного запуска, удаляется при
следующем запуске службы или задания.

## Настройки, которые хранит служба

**Параметры → Общие** — уровень журнала, уровень сжатия по умолчанию и папка
для **копии журнала** (флешка, другой диск) — полезно, когда проблема в самом
системном диске. Файл настроек пишет служба, поэтому окну для их изменения
права администратора не нужны.
